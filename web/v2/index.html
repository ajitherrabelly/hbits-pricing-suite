V2 Core Formulas

Bill Rate Formula

Bill = Sourced Wage × (1 + Markup%)

Where Markup% = 110% (fixed constant), 100% (guardrail)

Example:
Programmer/Expert, R1:
$39.66 × 2.10 = $83.30/hr bill
→ Rank #18/33, 38.5% margin

Cost & Margin (Unchanged)

Cost = Wage×(13.5%+3.5%+10.5%) + Bill×0.75% Margin% = (Bill - Wage - Cost) / Bill

OGS pass-through + overhead baked in

V2 Economics:
Bill $83.30 - Wage $39.66 - Cost $18.93
= $24.71 profit (38.5% margin)

V2 Implementation Rules

🎯 Wage Rule

Source from lowest-cost recruiter. Default: KBI-floor benchmark (proven #1 winner).

Independent Variable
📊 Markup Rule

Fixed 110% (never lower). Floor 100% only if guardrail (rank > #21) triggers.

Defended Margin
🛡️ Guardrail

If bill rank exceeds #21, lower wage estimate. Never thin the markup.

Competitive

Year-over-Year Escalation

Automatic Escalation

bill(year N) = wage(year N) × 2.10 Since markup is fixed (110%), bill escalates EXACTLY as wage escalates.
2026: wage $39.66 → bill $83.30
2027: wage $40.85 (+3%) → bill $85.79
(Margin stays locked at 38.5%)
